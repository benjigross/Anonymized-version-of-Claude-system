# Daily Brief

## 1. Read context
Read `CONTEXT.md` first (priorities, ranking rules, sources of truth, rules), then the reminders file.

## 2. Check every source of truth (since the last brief, or ~3 days)
1. **Gmail:** replies, recruiter emails, screening questions, scheduling, intros and LinkedIn
   application notices. Skip promotions and newsletters. Also check **sent** mail and **drafts**,
   since I often act directly in Gmail.
   - **Promised follow-ups:** scan sent mail for commitments ("I'll circle back in two weeks").
     Add each untracked one to the reminders file with a dated trigger; surface any that are due.
2. **Google Docs** listed in CONTEXT.md: to-do list, weekly schedule, per-firm sections.
   - **My schedule is the plan.** Anything not crossed off from an earlier day is **slipped** and
     ranks ahead of today's items.
3. **Google Calendar:** the next 7 days.
4. **The tracker** (all tabs) and the deal-ideas log.

## 3. Brief me (short, scannable)
- **Reminders first:** every open reminder whose date or condition is met (check conditions
  against evidence, e.g. the tracker or Gmail shows "applied").
- **Today / next 48h:** interviews and calls, with prep status.
- **Top 3–5 priorities, ranked** per CONTEXT.md. Scan the to-dos before ranking; never rank only
  by inbox activity.
- **New since last brief. Out of sync** (in Gmail/docs/calendar but not the tracker).
  **Waiting on me** (scores, approvals, decisions).
- **Writing library:** offer to save anything sent or submitted that isn't indexed yet.

## 4. Reconcile the tracker (after the brief)
- Add missing roles (log-role rules); update Status, Stage, Next Step, Last Activity, Notes.
- Add outreach rows; mark crossed-off to-dos Done.
- Check for an Excel lock file before writing. Regenerate the dashboard.
- Mark completed reminders done. Report what changed in 2–4 bullets.

## Rules
Never send anything; drafts only. Verify before asserting. Offer to draft owed replies.
