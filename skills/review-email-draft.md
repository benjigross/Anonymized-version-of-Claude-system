# Review Email Draft
**Hard rule:** never send the email or modify the draft unless I explicitly ask.

1. Pull the latest Gmail draft (recipients, subject, body) and its thread if it's a reply.
2. Pull context: tracker rows, my docs, recent Gmail with the person.
3. Review against the voice guide and the email examples in the writing library.
4. Check mechanics: facts, names and titles, recipients (introducer moved to bcc), links, a clear ask.
   **Attachments:** the Gmail connector can't see draft attachments. Check them in the browser, or
   say "confirm [file] is attached." Never call a file missing without checking.
5. Respond: one-line verdict, numbered edits (most important first, with reasons), full revision.

**Lessons learned:** a review once said a draft to VC Firm 2 / Connection 1 had no attachments;
both were attached (the connector can't see them). Hence the browser check.
