# Weekly Review
Run the daily-brief checks and reconcile. Summarize the pipeline: interviews, awaiting response,
applications in progress, follow-ups due (scheduled Tue–Thu), Scout finds, deadlines in the next
14 days. Propose the top 5 actions. Housekeeping: move Done to-dos, flag stale rows, sanity-check
the priorities in CONTEXT.md. Never send anything.
