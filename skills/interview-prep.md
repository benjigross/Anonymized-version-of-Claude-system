# Interview Prep
1. **Pick the stage.**
   - A. First conversation (1–2 pages): the person, firm basics, talk tracks, 1–2 pitches,
     2–3 portfolio views, questions.
   - B. Later rounds (full prep doc): what they may be unsure about, themes, pitches and how I'd
     diligence them, portfolio deep dives, sourcing, experiences and stories, case study, per-person sections.
2. **Listening and reading research:** every podcast, video, LinkedIn profile, firm post and news
   item for each person (current and prior roles) and the firm's key figures. Transcripts where
   available, otherwise an episode list for me. Each source gets takeaways and "how to use it."
   Also run before an application when I'm unsure where a firm invests.
3. **Portfolio research** per the diligence playbook (mode E).
4. **Fit and pitches** (diligence mode A).
5. **Cheat sheets:** questions; themes / pitches / portfolio companies; experiences.
After: capture notes and the firm's actual questions, update the tracker, draft a thank-you (never send).
