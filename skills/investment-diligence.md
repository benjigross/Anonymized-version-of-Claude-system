# Investment Diligence Playbook
Distilled from my own deal work, case studies and application pitches. Worked examples are kept
private; companies below are anonymized (Startup 1, 2…).

## 0. Pick the mode
| Mode | When | Output |
|---|---|---|
| **A. Pitch** | Application questions, nurture notes, deal-flow emails | QUICK TAKE / OVERVIEW / TEAM / WHY NOW / TO RETURN THE FUND / DEFENSIBILITY / RISKS, ~250 words |
| **B. Quick screen** | A newsletter company, a founder meeting | 1 page: what it is, the key question, bull/bear, pursue / pass / watch |
| **C. Full diligence / IC memo** | Real deal work | Recommendation, highlights/risks, company, traction, market, competition, returns, diligence list |
| **D. VC case study** | A recruiting case with a data pack | Mode C plus the case add-ons (§4) |
| **E. Portfolio research** | Before interviewing with a firm | Bullet notes per portfolio company, good/questionable verdicts, cross-portfolio themes (§6) |

## 1. Core process
1. **Find the hinge before modeling.** Write the bull case in one sentence. What single fact would
   falsify it (question #1)? What would make it true but not durable (question #2)? A load-bearing
   question changes value by multiples, not percentages. *Example: "demand-generating marketplace or
   supply-side tool?" drove both take rate and exit multiple for Startup 1.*
2. **Set the return bar.** `Required exit = fund size ÷ ownership at exit`. Assume terms in pitches
   and say so. The seed standard is a credible uncapped path, not a probable outcome.
3. **Why now and the market.** Test each trend with a cited stat. Size TAM two ways (top-down and
   bottoms-up). Compare a capture model to TAM × share, never to TAM. Tag every input with a source or
   "Assumption." Treat a new payer as additive optionality, not base case.
4. **Traction quality.** Trailing-3-month figures; split in-market vs. new-market growth; cohorts;
   NDR by tier; concentration; stage benchmarks; always state run-rate vs. actual.
5. **Unit economics.** Decompose take rate. Burn multiple = net burn ÷ net new revenue
   (<1x amazing, 1–1.5 great, 1.5–2 good, 2–3 suspect, >3 bad). Tie cost buckets to reported net loss.
6. **Competition: borders, not logos.** Concede the niche; map 3–5 adjacent categories (has / lacks);
   state the squeeze; rank threats conditional on the key question; consolidation creates buyers.
7. **Defensibility and risks.** Name the real moat, or say "thin today." Rank risks; in memos every
   risk carries an ask. A risk you can't ask about is a reason to pass.
8. **Returns.** A grid, not a point estimate (`EV = revenue × take rate × multiple`); pair levers
   that share a root cause; model dilution and delay; check the macro in the exit year, not today.
9. **Primary research.** Use the product, visit, talk to a churned user, run expert calls, check
   pricing pages and reviews. Report sample size honestly. State the counter-argument yourself.
10. **Recommendation.** Lead with the stance: invest, pass, or "not yet, with these asks." Say what
    would change my mind.

## 2. Pitch rules (mode A)
- The quick take is my own one-liner. Tie to the firm's thesis once; use its portfolio as analogies.
- Lead with a real personal edge ("I met the CEO," "as an active user").
- Verify every traction number, funding figure and date (these have been wrong before).
- Don't oversell ("maps directly," "perfectly"). 2–5 risks, biggest question named.
- Write the natural-length version first, then cut to the limit with small cuts I choose.

## 3. Checks before anything ships
Every number ties to a source; re-check cross-references after edits; consistent periods; no double
counting; competitor facts checked against primary sources; confidential data never goes into a
third-party document or reusable example.

## 4. Case study add-ons (mode D)
Evaluation-date convention in line 1; construct the deal if no terms are given; decode the data pack
(run-rate vs. actual, mismatched periods) and treat each reconciliation as a finding; a firm-fit
section; lock the stance by the halfway point; send a heads-up before a deadline if running late;
prep the 6–8 likeliest pushbacks; afterwards, log the firm's actual questions.

## 6. Portfolio research (mode E)
1. Pick 4–6 companies covering core theses, recent deals and an exit.
2. Give each a verdict, including one honest "questionable" pick ("at the time of investment, the case was…").
3. Bullet notes: overview / business model / team / path to $1B / traction / moat / exits / risks.
4. Find the one structural insight that makes the company work.
5. Pressure-test the moat with a specific mechanism and a real event.
6. Do back-of-envelope math on one risk.
7. Check acquirer context for exits.
8. Draw cross-portfolio themes and map them to my theses as talking points.
9. End each with open questions; leave `[ ]` placeholders rather than guessing.
