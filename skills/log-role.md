# Log Role / Tracker Workflow
**Always first:** read `CONTEXT.md`. It overrides anything below if they conflict.

## Research rules
- Location: [home city] or remote only. A company HQ'd locally whose role is listed elsewhere doesn't count.
- Stage buckets: Founding = no raise / pre-seed; Early = seed or Series A; Growth = Series B+.
- Funding research: record round, month + year, $ raised, valuation if available. Two articles
  within ~4 months = same round. If not publicly indexed, say so rather than guessing.

## Tabs
- **Investor Roles**: Firm | Title | Interest | Fit | Strategy / Stage | Job Link | Firm Overview |
  Team Size | Fund Size | Notable Investments | Background Required | Responsibilities |
  Application Requirements | Office Policy | Date Posted | Deadline | LinkedIn 1st° | LinkedIn 2nd° |
  Status | Interview Stage | Next Step | Last Activity | Notes
- **Startup Roles**: same, with company fields (headcount, latest round, total raised, key investors).
- **Networking Targets** (no open posting), **Outreach Log** (one row per person), **Inbox (Auto)** (Scout finds).

## Prioritization (drives Next Step)
- **Interest 1 = resume drop only.** Minimal next step; no networking prescribed.
- **Interest 2–3 = network in.** Next Step names the best warm path (Connection 1, via Connection 2),
  and may suggest applying only with the intro. Interest, not Fit, drives effort.

## Column rules
- **Fit (1–3):** scored against my background. 3 = clean match on years and experience type;
  2 = a stated preference I don't meet, or a judgment call; 1 = a hard requirement I don't meet.
- **Application Requirements:** check the actual form; copy questions verbatim with limits.
  If the form isn't viewable, say so. Never guess.
- **Office Policy / Dates:** from the posting or ATS metadata; "Not stated" if unavailable.

## Workflow 0: Quick read ("should I apply?")
~5 lines: what it is; fit vs. CONTEXT.md; Fit score; any existing connection or prior contact;
recommendation (apply / network first / skip) with one reason. Then ask whether to log it.

## Workflow 1: I drop a job link
0. **Check what has already happened first:** Gmail (confirmations, recruiter emails, intros) and my
   docs. Set Status from evidence; never assume "Not Applied."
1. Fetch the posting (browser if JS-rendered). 2. Classify the tab.
3. Research the firm or company (2–4 searches); mark uncertain figures `~`.
4. Extract background required and a 1-line responsibilities summary.
5. **LinkedIn warm paths:** use the company People page filtered to my 1st/2nd-degree network
   (keyword search misses people whose headline is just "CTO at Startup 1"). Record 1st° by name and
   the best 2nd° via-names. Skip for Interest 1.
6. Update an existing row instead of duplicating. 7. Append the row with a suggested Next Step.
8. Confirm in 1–2 sentences.

## Workflow 2–4
Networking targets (1–3 sensible contacts), outreach sync from Gmail and Calendar (replies,
follow-ups due, stale threads), and Inbox (Auto) review.

## Rules
- Check for an Excel lock file before any write; never silently drop updates.
- Never fabricate funding data or connection names; write "not found."
- If the company fits a thesis, add it to the deal-ideas log. Draft only: never send outreach.
